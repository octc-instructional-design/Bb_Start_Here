Browser Troubleshooting

A link won’t open

Your browser may be blocking a pop-up. Allow it for the course site, then retry.

Pop-up settings:

  • Chrome (opens in a new tab)
  • Edge (opens in a new tab)
  • Safari on Mac (opens in a new tab)

A page is stuck

Refresh it. Then try another browser or clear its cache and cookies.

Check your browser (opens in a new tab)

Clear site data or adjust pop-ups

Clearing cookies may sign you out of a website and prompt you for MFA again. After changing a setting, close and reopen the browser before retrying.

  • Clear Chrome browsing data (opens in a new tab)
  • Clear Edge browsing data (opens in a new tab) or allow Edge pop-ups (opens in a new tab)
  • Clear Firefox site data (opens in a new tab) or allow Firefox pop-ups (opens in a new tab)
  • Clear Safari site data (opens in a new tab) or allow Safari pop-ups (opens in a new tab)

A tool won’t open in the app

If a tool does not work in the Blackboard app, try a supported browser.
